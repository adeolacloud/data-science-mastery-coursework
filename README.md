# Data Science Core Coursework

A structured repository holding core data science practice modules across Python, statistics, SQL, and machine learning.

---

## 📁 Modules Overview

* **`01-python-foundations/`**: Foundational scripts covering string formatting, custom statistics calculations, and data cleaning.
* **`02-math-and-statistics/`**: Statistical analysis, hypothesis testing, and probability distributions.
* **`03-sql-and-advanced-analysis/`**: SQL queries (Joins, CTEs, Window Functions) and Pandas data wrangling.
* **`04-machine-learning-algorithms/`**: Model building, feature engineering, and evaluation metrics.

---

## 🛠️ Tech Stack
Python 3.x, SQL, NumPy, Pandas, Scikit-Learn
